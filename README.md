# kimpo-attachment-docx

Kimpo 附件插件：文档查看与编辑（docx-preview + SuperDoc），AGPL-3.0

Kimpo 附件插件（surface `attachment.open`，纯前端）。契约见主仓 plugins/kimpo-plugin-sdk/frontend/src/attachment-open.ts；立案 somsne/kimpo#768。

本仓骨架由阶段 0 建立，功能开发在阶段 1 的子会话里进行。
